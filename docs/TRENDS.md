# 圈子里的说法和流量密码（给以后每天逛圈的自己看）

> 每天逛圈后更新。每条带日期和一句原话、互动数。不再有人用的删掉。不写别人的用户名和链接。

## 怎么逛（工具的坑）

- 2026-11-12：Threads 搜索页不登录时，**单个常见词能出结果**（badminton、羽毛球、羽球臨打），**多词和地名组合几乎全是 No results**（badminton LA、badminton open play、洛杉磯 羽球、洛杉矶羽毛球、badmintonmemes）。有的词（羽球、badmintonlife、shuttlecock）抓回来是空页。别在这些上浪费次数。
- 搜索结果是“热门 + 最近”混排，几个月前的高赞帖会一直挂在前面。
- 我们自己的主页不登录能看到简介、粉丝数和帖子（2026-11-12 还是 “No threads yet”，0 粉丝）。

## 一直有效的（中文，台湾为主）

- **示弱 + 一个问句 + 地点价钱丢在最后**：“都沒人😭😭😭 誰要來打羽球， 雲林縣立體育館 $80/人”（2026-11-12 看到时 1.8K 赞、145 回复）。还在搜索页最前面。
- **工具推荐帖被疯狂转发**：“這個臨打app超方便的，好誇張”（1.6K 赞、104 回复、**2.9K 分享**，2026 年 4 月的帖子，11-12 还挂在“羽球臨打”第一条）。一句话、没说是哪个 app，大家在回复里问。说明台湾球友对“臨打 app”有现成需求，也有对手。
- **新手怕被虐**：台南新手徵固定球友，“不要太強”（160 赞、47 回复、40 分享）。“新手友善”“不要太強”是高共鸣点。
- **能站队的话题**：双打里自称很强却叫搭档顾前场（55 赞、37 回复）；“看比赛的女单迷和男单迷是两拨人”（193 赞、34 回复）。回复数比赞数比例高，就是在吵。
- **下班选打球**：“吃饭看电影，或者下班有空打羽球？”（127 赞）。

## 互动低的格式（别学）

- 公告式招人帖（时间、地点、级数、价钱、人数、球种列一排）：马来西亚、香港、多伦多、屏东的都是个位数到二三十赞，只有分享数（被转进群里）。
- 英文 “babe wake up we need to start our badminton training”：2 赞。babe wake up 这个格式在羽毛球圈没起来。
- 2026-11-12 看到一条招人帖被 Threads 自动标了 “AI content”。平台会打这个标签。
